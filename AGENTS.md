# MAISON Python portfolio

- The application uses Flask and Jinja, not Next.js or React.
- Business rules and input validation belong in domain.py.
- Keep visible UI copy in i18n.py and support both Japanese and English.
- Use fictional customer data only. LINE integration is a UI preview.
- Keep public/assets for Vercel CDN assets, with Flask routes for local development.
- Run `python -m unittest discover -s tests -v` before publishing.
