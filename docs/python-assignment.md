# Python課題としての説明

## 作品概要

販売スタッフが担当顧客への連絡を忘れないためのWebアプリです。PythonとFlaskで、顧客データの検証、会話記録、アラート判定、検索・絞込・集計、HTMLの生成を行います。ブラウザ側のJavaScriptは通信と操作、localStorage保存を担当します。

## 説明できるPythonの要素

- 辞書・リスト：顧客、スタッフ、会話のデータ表現
- 関数分割：`alert_for`、`profile_fields`、`add_activity`
- 条件分岐：未返信、期限超過、14日経過等の優先順位
- 日付処理：`datetime`、`timedelta`、`zoneinfo`
- ソート：会話日付、対応優先度、名前など
- 例外処理：不正入力をHTTP 400として返す
- Web：Flaskのルート、JSONリクエスト、Jinjaテンプレート
- 多言語：辞書から表示言語に対応する文字列を取得
- テスト：標準ライブラリ`unittest`で境界条件とAPIを検証

## 発表デモの流れ

1. ダッシュボードでウィンの担当顧客と赤い未返信ラベルを見せる。
2. 顧客詳細から今日の送信を記録し、次回フォローを1週間後にする。
3. 未返信が解除されて当日対応になることを示す。
4. 言語をEnglishに切り替え、名前・状態・会話サンプルの表示を確認する。
5. スマホ幅で顧客一覧がカードになることを示す。
6. `domain.py`の`alert_for`とテストを説明する。

## 起動と確認

READMEの手順でPython 3.12以降の仮想環境を作成します。

```sh
python app.py
python -m unittest discover -s tests -v
```

DB保存は実装せず、架空データをブラウザに保存します。学校側に「Flask禁止」「SQL必須」「クラス必須」等の条件がある場合は、その課題条件に合わせた調整が必要です。
